# SaasPulse Landing Page

A minimal SaaS landing page built with React, TypeScript, and Tailwind CSS.

## Features

- Modern and responsive UI
- Hero section with clear call to action
- Transparent pricing section with three plans
- Customer testimonials to build trust
- CTA section for conversion
- Gradient background and smooth animations

## Setup

1. Clone the repository.
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`

## Technologies

- React 18
- TypeScript
- Tailwind CSS
- Vite
